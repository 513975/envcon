# EnvCon 0.5.3：首轮持续改进

关联 ROADMAP 的 IMP-01-A、IMP-07-A、IMP-05-A；三个长期方向仍进行中，本轮不覆盖完整持久化扫描缓存、全配置回滚或完整 Windows 矩阵。

## 已实现行为

- 包管理器配置页与缓存页共享同时发生的工具配置查询；完成值不保留在后端，减少外部改动后的陈旧结果。手动强制刷新绕过旧的普通查询，同时发生的强制刷新仍共享新查询；写操作前后断开旧查询的复用。
- 缓存清理前仍独立查询实际路径，不使用页面结果授权删除。
- 读取有效环境变量仅读取进程/注册表快照，不再隐式遍历常见安装目录；正式系统扫描仍完整发现这些目录。
- 前端缓存失效或发起新刷新后，旧成功/错误响应转接最新查询，避免旧结果覆盖页面。
- 应用配置新增 schema_version=1；兼容旧版缺省字段并保留未知字段。格式损坏、读取失败或未来 schema 会显式提示，阻止保存及管理根目录默认回退。
- 配置保存采用跨实例文件锁、保存前原文件内容核对、唯一同目录临时文件、flush 与 Windows 替换；保留 config.previous.json。保存失败不更新内存根目录。
- 设置页提供重新加载、恢复上次有效配置与打开配置目录。恢复需确认，保留 config.before-recovery-*.json 原文件；不移动环境或修改 PATH。无有效备份时恢复按钮不可用。

## 配置写入审计与后续边界

| 写入入口 | 当前保护 | 后续工作 |
| --- | --- | --- |
| AppConfig / config.json | schema、同目录替换、上次有效备份、跨实例锁、外部修改核对、显式恢复 | 多份历史和选择性恢复；磁盘满/断电故障注入 |
| 用户 PATH / 环境变量 | 原实现已有写前备份，PATH 保留注册表字符串类型；不套用 JSON 文件机制 | PATH 读改写并发、备份完整性和多变量回滚 |
| npm/pnpm/Yarn/pip 配置 | 原 CLI 写入，部分失败报告已完成项；本轮复用不参与执行前复核 | 执行前导出配置、失败后逐项恢复；目前不是多字段原子事务 |
| Cargo/uv 等环境变量型配置 | 原注册表备份与独立变量写入 | 多字段操作的一致性与回滚 |
| 前端读取 | 写前/写后缓存失效及旧 Promise 响应保护 | 所有 keep-alive 页面刷新触发覆盖仍需继续审计 |

文件锁只协调遵守该锁的 EnvCon 实例。非协作外部编辑器在内容复核之后的瞬间写入，仍不构成跨程序事务。前端既有 60 秒完成值缓存保留，手动刷新可绕过；后端本轮仅合并在途请求。

首次保存没有旧配置时不会生成“上次”备份；旧格式在首次成功保存时迁移。恢复前副本不自动清理，防止丢失故障证据。坏配置无法恢复且无有效备份时，应先人工修复/保存原文件，再重新加载，应用不自动重置。

## 本机基准

2026-09-18，同一 Windows 本机、十管理器、root=None、无项目目录，连续三组只读查询。基准测试 `commands::tests::host_query_benchmark`，无真实包安装、卸载或 PATH 写入。

| 样本 | 原独立双查询 | 共享双查询 | 命令尝试次数（前 / 后） |
| --- | ---: | ---: | ---: |
| 1 | 4,169 ms | 3,417 ms | 68 / 34 |
| 2 | 4,067 ms | 3,189 ms | 68 / 34 |
| 3 | 4,076 ms | 3,458 ms | 68 / 34 |
| 平均 | 4,104 ms | 3,355 ms | 68 / 34 |

该场景平均耗时减少约 18.3%，命令尝试数减少 50%。系统文件缓存、机器负载和管理器配置会影响结果，不是整机冷启动提速承诺。

同一轮比较读取环境变量三次：原完整目录发现路径合计 269,511 µs，拆分快照后合计 2,439 µs。该项只说明消除了不必要目录遍历，不能外推完整系统扫描速度。
