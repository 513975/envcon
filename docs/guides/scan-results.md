# 本机扫描结果（0.4.1）

入口：环境管理 → 本机工具与包管理器 → 开始扫描。可添加最多 8 个项目或虚拟环境目录参与扫描。

## 汇总与分类

结果按语言与运行时、包管理器、构建工具、其他工具分类。摘要分别统计工具种类、具有可用入口的工具种类、命令入口总数及待检查入口数。

同一工具的多个目录归在一组，默认只显示版本摘要、入口数量、异常数量和 PATH 首选路径。展开工具可查看每个入口的版本、文件路径、来源和状态。绿灯表示该组至少有一个入口成功取得版本，不表示组内所有入口均正常。

“入口”不是独立安装数量。例如 pip.exe 和 python.exe -m pip 可能属于同一个 Python 环境，因此放到 pip 组中，分别保留其探测结果。同名同版本但安装路径不同的环境也保留各自记录，避免隐藏多版本和路径冲突。

## 搜索与诊断

- 分类按钮按工具种类计数；可进一步筛选可用或待检查入口。
- 搜索覆盖工具、版本、路径、来源、命令、错误、安装根目录及实际文件路径；搜索和状态筛选自动展开匹配项。
- “探测详情”显示实际命令、安装根目录及解析后的文件路径，字段缺失时不推断补齐。
- PATH 首选保留扫描时的含义，不承诺与终端别名或已激活虚拟环境一致；即便首选入口失败，也保留其首选身份并标记待检查。
- 原有打开所在目录和纳入管理操作位于具体入口中。仅可用、结构兼容的环境可纳入，项目环境及模块入口继续遵守后端限制。

0.4.1 调整展示与交互，不按版本号删除重复结果。扫描深度、权限和目录限制继续通过“扫描提示”保留。

## 0.5.0 旧包来源扫描

“本机工具与包管理器”发现运行环境与命令入口；包管理器页新增“旧包扫描”发现安装包来源目录，两者用途不同。旧包扫描覆盖十种开发包管理器，可选择常见位置、本地磁盘或指定目录，按管理器/目录显示安装数量、可恢复数量及来源诊断，展开后直接进入重装。详见 [包管理器说明](package-managers.md)。
