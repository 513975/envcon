工作原理

目录即真相,Junction 即切换

D:\DevEnv\
├── envs\                 # 各类型环境的多版本仓库
│   ├── jdks\temurin-21\
│   └── nodes\node-22\
├── current\              # Junction 指针(切换版本 = 重指链接)
│   ├── jdk   →  envs\jdks\temurin-21
│   └── node  →  envs\nodes\node-22
└── globals\              # npm/pip 等全局包与缓存

PATH 中只需保留一条 current\* 路径:切换版本时 Junction 重新指向目标目录, PATH 保持不变；将 current 路径置于优先位置后，新开终端即可使用所选版本。散装环境同样以 Junction 纳入，原安装位置不动。
